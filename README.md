# 🤖 AI Autopilot

เขียนงานไว้ในแอป (ใช้ได้ทั้งคอมและ Android) แล้ว Claude จะทำให้บนคลาวด์ในช่วงเวลาที่คุณตั้งไว้ แม้ตอนปิดคอมหรือนอนหลับอยู่
แต่ละงาน AI จะวิเคราะห์และแตกเป็นขั้นตอนย่อย → ลงมือทำ → ทดสอบและแก้บัคเอง → ติ๊กว่าเสร็จ
ถ้าติด limit ของ Claude จะพักไว้ แล้วกลับมาทำต่ออัตโนมัติเมื่อ limit รีเซ็ต

## การทำงาน
```
แอป (คอม / Android) ──เขียนงาน/ตั้งเวลา──▶  GitHub repo  ◀──อ่าน/อัปเดตงาน── GitHub Actions + Claude Code
                                         tasks.json  config.json  workspace/
```
- `tasks.json` เก็บรายการงาน แผน และบันทึกการทำงาน (แอปกับ AI แก้ไฟล์นี้ร่วมกัน และรวมข้อมูลให้อัตโนมัติถ้าแก้พร้อมกัน)
- `config.json` เก็บช่วงเวลาทำงาน (ตั้งในแอปได้)
- `workspace/<id งาน>/` เก็บผลงานที่ AI สร้าง
- ระบบตื่นมาเช็กทุกชั่วโมง ถ้าอยู่ในช่วงเวลาที่ตั้งไว้และมีงานค้าง ก็จะทำงานต่อ (รอบหนึ่งไม่เกิน 5 ชั่วโมง)
- ปุ่ม "เริ่มทำงานตอนนี้" ในแอป สั่งให้เริ่มทันทีโดยไม่ต้องรอช่วงเวลา

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1) เอา Token ของ Claude Pro (ทำบนคอม)
1. ติดตั้ง Node.js จาก https://nodejs.org (เลือกรุ่น LTS)
2. เปิด Terminal (Mac) หรือ PowerShell (Windows) แล้วพิมพ์
   ```
   npm install -g @anthropic-ai/claude-code
   claude setup-token
   ```
3. ล็อกอินด้วยบัญชี Claude Pro ในเว็บที่เด้งขึ้นมา แล้วคัดลอก token ที่ขึ้นต้นด้วย `sk-ant-oat…` เก็บไว้ (อย่าส่งให้ใคร)

### 2) ใส่ Token ลงใน GitHub repo
repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
- Name: `CLAUDE_CODE_OAUTH_TOKEN`
- Secret: วาง token จากขั้นที่ 1

### 3) อนุญาตให้ระบบบันทึกผลงานลง repo
repo → **Settings** → **Actions** → **General** → หัวข้อ *Workflow permissions* → เลือก **Read and write permissions** → Save

### 4) เปิดเว็บแอป (GitHub Pages)
repo ที่มีโฟลเดอร์ `docs/` → **Settings** → **Pages** → Source: *Deploy from a branch* → Branch: `main` โฟลเดอร์ `/docs` → Save
รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### 5) สร้าง Token ให้แอปเข้าถึงข้อมูล
GitHub → รูปโปรไฟล์ → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
- Expiration: 1 ปี (หรือตามต้องการ)
- Repository access: *Only select repositories* → เลือก repo ที่เก็บงาน
- Permissions → Repository permissions: **Contents = Read and write**, **Actions = Read and write**
- กด Generate แล้วคัดลอก token (`github_pat_…`)

### 6) ติดตั้งแอปบนคอมและมือถือ
- **Android:** เปิดลิงก์แอปใน Chrome → เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก*
- **คอม:** เปิดลิงก์ใน Chrome/Edge → กดไอคอนติดตั้งท้ายช่อง URL
- เปิดแอป → แท็บ 🔑 ตั้งค่า → ใส่ชื่อบัญชี GitHub, ชื่อ repo ที่เก็บงาน และ token จากขั้นที่ 5 (ใส่ครั้งเดียวต่อเครื่อง)

### 6.1) (ทางเลือก) ติดตั้งเป็นไฟล์ APK บน Android
ทุกแอปจะถูกสร้างเป็นไฟล์ APK อัตโนมัติ ดาวน์โหลดได้ที่หน้า **Releases → 📱 แอป Android (APK)** ของ repo
(`https://github.com/<ชื่อบัญชี>/<ชื่อ repo>/releases/tag/apps`)
1. เปิดลิงก์บนมือถือ กดไฟล์ `.apk` ที่ต้องการเพื่อดาวน์โหลด
2. กดเปิดไฟล์ที่ดาวน์โหลด → ถ้ามีข้อความ "ไม่อนุญาตให้ติดตั้งจากแหล่งที่ไม่รู้จัก" ให้กด **ตั้งค่า** → เปิด **อนุญาตจากแหล่งนี้** → กลับมากด **ติดตั้ง**
3. ถ้า Google Play Protect เตือน ให้กด **รายละเอียดเพิ่มเติม → ติดตั้งต่อไป** (เตือนเพราะแอปไม่ได้มาจาก Play Store)
4. เวอร์ชันใหม่: ดาวน์โหลดไฟล์ใหม่แล้วติดตั้งทับได้เลย ข้อมูลเดิมไม่หาย

### 7) ลองใช้งาน
1. แท็บ 📋 งาน → เพิ่มงาน เช่น "เขียนโปรแกรม Python คำนวณ BMI พร้อมเทสต์"
2. แท็บ ⚙️ สถานะ → กด **เริ่มทำงานตอนนี้**
3. รอสักครู่ กดเข้าไปในงานจะเห็นแผนที่ AI วิเคราะห์ ขั้นตอนที่ติ๊กแล้ว และบันทึกการทำงาน

### 8) (ทางเลือก) นำเข้าโปรเจคจาก GitHub repo อื่นของคุณ
1. แก้ token ที่ https://github.com/settings/personal-access-tokens → Repository access เลือก **All repositories**
   และ Permissions เพิ่ม **Contents** กับ **Pull requests** เป็น Read and write
2. ไปที่ repo `ai-autopilot` → Settings → Secrets and variables → Actions → New repository secret
   ชื่อ `GH_REPO_TOKEN` วาง token เดียวกัน
3. ในแอป แท็บ 🔑 ตั้งค่า → "🐙 นำเข้าโปรเจคจาก GitHub" → โหลดรายชื่อ repo → เลือกทั้งหมด → นำเข้า
4. เพิ่มงานในโปรเจคนั้นได้ตามปกติ AI จะทำบน branch `ai-autopilot/<id งาน>` แล้วเปิด Pull Request ให้คุณตรวจก่อน merge

## ใช้งานประจำวัน
- **เพิ่มงาน:** พิมพ์สิ่งที่อยากได้ ยิ่งเขียนรายละเอียดชัด ผลงานยิ่งตรงใจ
- **เลือกโมเดล AI:** ตั้ง "โมเดลหลัก" ในแท็บ ⏰ เวลา/AI แล้วเลือกโมเดลเฉพาะงานได้ตอนเพิ่มงานหรือในหน้างาน (Sonnet = สมดุล, Opus = เก่งสุดแต่ใช้โควตาเร็ว, Haiku = เร็ว/ประหยัด) ถ้าแพ็กเกจใช้โมเดลที่เลือกไม่ได้ ระบบจะสลับไปใช้ค่าเริ่มต้นให้เอง
- **ตั้งช่วงเวลา:** แท็บ ⏰ เลือกวันและเวลา (เช่น ทุกวัน 23:00–07:00) ช่วงที่ข้ามเที่ยงคืนก็ตั้งได้
- **งานสถานะ "ต้องการคุณ":** AI ติดอะไรบางอย่าง ให้เปิดงานนั้นอ่านบันทึก แล้วตอบในช่อง "ส่งข้อความถึง AI" รอบหน้า AI จะทำต่อ
- **สั่งแก้งานที่เสร็จแล้ว:** ส่งข้อความถึง AI ในงานนั้น ระบบจะเปิดงานให้ทำต่อ
- **ดูผลงาน:** กดลิงก์ `workspace/…` ในหน้างาน

## ข้อจำกัด
- AI ทำงานในเครื่องคลาวด์ชั่วคราว ทำได้ดีกับงานเขียน ค้นคว้า เขียนโค้ด สร้าง/ทดสอบไฟล์ แต่ใช้โปรแกรมบนคอมคุณหรือล็อกอินเว็บด้วยบัญชีคุณไม่ได้
- Claude Pro มี limit การใช้งาน งานใหญ่ๆ อาจใช้เวลาหลายคืน (ระบบรอแล้วทำต่อให้เอง)
- GitHub อาจเลื่อนเวลารันตามตารางไปบ้าง (ปกติไม่กี่นาที)
- ถ้า repo เป็น **private**: GitHub Actions ให้ใช้ฟรี 2,000 นาที/เดือน หมดแล้วระบบจะหยุดจนถึงเดือนถัดไป (ไม่มีการเก็บเงินถ้าไม่ได้ผูกบัตร)
  ถ้าเป็น **public**: ใช้ได้ไม่จำกัด แต่คนอื่นเห็นงานและผลงานได้ — ห้ามใส่ข้อมูลลับ
- ห้ามเขียนรหัสผ่านหรือข้อมูลลับลงในงาน

## ปรับแต่ง (ไม่บังคับ)
ตั้งค่าใน `.github/workflows/autopilot.yml` ส่วน `env:`
- `RUN_BUDGET_MINUTES` เวลาสูงสุดต่อรอบ (ค่าเริ่มต้น 300)
- `SESSION_MINUTES` เวลาสูงสุดที่ให้ AI ทำงานหนึ่งครั้งก่อนบันทึก (ค่าเริ่มต้น 45)
คำสั่งที่ AI ใช้ทำงานอยู่ใน `prompts/agent.md`
