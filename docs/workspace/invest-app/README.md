# คลังความรู้การลงทุนไทย

เว็บแอป static (HTML/CSS/JS ล้วน ไม่มี backend) รวบรวมข้อมูลการลงทุนที่น่าสนใจสำหรับคนไทย พร้อมตัวช่วยวางกลยุทธ์การลงทุน

> ⚠️ จัดทำขึ้นเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน ตัวเลขผลตอบแทน/ความเสี่ยงเป็นข้อมูลโดยประมาณ โปรดตรวจสอบข้อมูลล่าสุดจากแหล่งอ้างอิงก่อนตัดสินใจลงทุนจริง

## ฟีเจอร์

- **ภาพรวม** — การ์ดสรุปการลงทุนในไทย 8 ประเภท (หุ้นไทย, หุ้นต่างประเทศ/ETF, กองทุนรวม, ตราสารหนี้, เงินฝาก, ทองคำ, คริปโท, REITs) คลิกดูรายละเอียด ผลตอบแทน ความเสี่ยง สภาพคล่อง เงินขั้นต่ำ ภาษี ช่องทางลงทุน ข้อดี/ข้อเสีย และแหล่งที่มา
- **ลงทุนทั่วโลก** — การ์ดสรุปสินทรัพย์ลงทุนต่างประเทศ 8 ประเภท แยกตามภูมิภาค (หุ้นสหรัฐฯ, หุ้นยุโรป, หุ้นญี่ปุ่น, ตลาดเกิดใหม่, ตราสารหนี้โลก, REITs ต่างประเทศ, สินค้าโภคภัณฑ์โลก, Forex) รูปแบบเดียวกับแท็บภาพรวม
- **เปรียบเทียบ** — ตารางเปรียบเทียบทุกประเภททั้งในไทยและทั่วโลก (รวม 16 ประเภท) + กราฟกระจาย ความเสี่ยง vs ผลตอบแทนคาดหวัง
- **ประเมินความเสี่ยง** — แบบทดสอบ 4 ข้อ ประเมินความเสี่ยงที่รับได้ แล้วแนะนำสัดส่วนพอร์ต (Asset Allocation)
- **เครื่องคำนวณ** — ชุดเครื่องมือทำกำไร 8 แบบ: DCA รายเดือน, ดอกเบี้ยทบต้น, เป้าหมายเงินก้อน/เกษียณ, กำไร/ขาดทุนจากการซื้อขาย (รวมค่าธรรมเนียม), Position Sizing ตามความเสี่ยงที่รับได้, ผลตอบแทนเงินปันผล (Dividend Yield), แปลงสกุลเงิน (THB/USD/EUR/JPY โดยประมาณ), ผลกระทบเงินเฟ้อต่อมูลค่าเงิน
- **กลยุทธ์ตัวอย่าง** — 3 แบบ: ระมัดระวัง / สมดุล / เติบโต พร้อมสัดส่วนพอร์ตและหมายเหตุ

## วิธีเปิดใช้งาน

ข้อมูลโหลดจากไฟล์ `data/*.json` ผ่าน `fetch()` ซึ่งเบราว์เซอร์ส่วนใหญ่จะ**บล็อกการโหลดไฟล์ JSON ถ้าเปิด `index.html` ตรงๆ แบบ `file://`** จึงแนะนำให้รันผ่านเว็บเซิร์ฟเวอร์เล็กๆ ในเครื่อง:

```bash
cd workspace/invest-app
python3 -m http.server 8000
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

(หรือใช้ส่วนขยาย "Live Server" ของ VS Code ก็ได้)

## โครงสร้างไฟล์

```
invest-app/
├── index.html              หน้าเว็บหลัก (6 แท็บ)
├── style.css               สไตล์ (รองรับจอมือถือ)
├── app.js                  โลจิกทั้งหมด (tabs, การ์ด, กราฟ, แบบประเมิน, เครื่องคำนวณ)
└── data/
    ├── investments.json         ข้อมูลการลงทุนในไทย 8 ประเภท พร้อมแหล่งที่มา/วันที่
    ├── global-investments.json  ข้อมูลการลงทุนทั่วโลก 8 ประเภท พร้อมแหล่งที่มา/วันที่
    └── strategies.json          กลยุทธ์ตัวอย่าง 3 แบบ (ใช้ทั้งหน้ากลยุทธ์และผลแบบประเมินความเสี่ยง)
```

การอัปเดตข้อมูล (ตัวเลขผลตอบแทน แหล่งที่มา ฯลฯ) ทำได้โดยแก้ไฟล์ JSON ใน `data/` โดยตรง ไม่ต้องแตะโค้ด

## ผลการทดสอบ

ทดสอบด้วย Playwright (Chromium) ทั้งจอคอม (1280x900) และจอมือถือ (390x844):

- โหลดหน้าเว็บ ครบทั้ง 8 การ์ด, เปิด/ปิด modal รายละเอียดได้, แสดงแหล่งที่มา
- ตารางเปรียบเทียบครบ 8 แถว และกราฟความเสี่ยง-ผลตอบแทนกระจายจุดถูกต้องตามข้อมูล
- แบบประเมินความเสี่ยง 4 ข้อ ให้ผลและสัดส่วนพอร์ตตามคะแนน
- เครื่องคำนวณ DCA / ดอกเบี้ยทบต้น / เป้าหมายเงินก้อน คำนวณถูกต้องตรงกับสูตรการเงินมาตรฐาน
- หน้ากลยุทธ์ตัวอย่างครบ 3 แบบ สัดส่วนพอร์ตรวมได้ 100% ทุกแบบ
- ไม่มี error ใน console ทั้งจอคอมและจอมือถือ ไม่มี horizontal overflow บนจอมือถือ

**บัคที่พบและแก้แล้ว:** ฟังก์ชันคำนวณตำแหน่งจุดในกราฟเปรียบเทียบ (`approxReturnMidpoint` ใน `app.js`) แปลความหมายขีด "-" ในข้อความช่วงตัวเลข (เช่น "6-10%") ผิดเป็นเครื่องหมายลบ ทำให้ผลตอบแทนเฉลี่ยของแทบทุกประเภทกลายเป็นค่าติดลบ จุดทั้งหมดจึงไปกองที่มุมล่างของกราฟทับกัน แก้โดยแปลงขีดระหว่างตัวเลขเป็นช่องว่างก่อนตัดคำนวณ และตัดส่วนข้อความหลังคำว่า "แต่" (ส่วนขยายเรื่องความผันผวน/กรณีเลวร้าย) ออกก่อนคำนวณค่าเฉลี่ย
